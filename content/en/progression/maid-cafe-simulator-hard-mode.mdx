No separate Hard Mode is confirmed in the official sources checked here. What exists is a choice between Normal Mode and Story Mode when starting a new game, added in v1.21 (October 23, 2026).

What the modes do

- Story Mode: cafe XP, Bond and income are doubled, and most of the challenge of running the cafe is removed.
- Normal Mode: the standard experience.
- The mode is saved per save file and shown on the load screen and pause menu.
- Once chosen, the mode can't be changed later.
- Existing saves continue in Normal Mode; Story Mode requires a new game.

The irreversible per-save choice is easy to miss: if you pick Normal Mode and want the doubled Story Mode values later, you must start over. No in-game toggle is described in the notes.

Whether a higher-difficulty mode is planned is not stated in the sources checked here. For current details, check the Steam store and Accelix's official announcements.
